# Add Two Integers

**Difficulty:** `Easy`

## Problem

Given two integers num1 and num2, return the sum of the two integers.

Read num1 and num2 from standard input (space-separated on one line), and print their sum to standard output.

## Examples

### Example 1

**Input**
```
12 5
```
**Output**
```
17
```

**Explanation:** 12 + 5 = 17.

### Example 2

**Input**
```
-10 4
```
**Output**
```
-6
```

**Explanation:** -10 + 4 = -6.

### Example 3

**Input**
```
0 0
```
**Output**
```
0
```

**Explanation:** 0 + 0 = 0.
