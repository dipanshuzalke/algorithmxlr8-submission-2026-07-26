# Squares of a Sorted Array

**Difficulty:** `Easy`

## Problem

Given an integer array nums sorted in non-decreasing order, return an array of the squares of each number, also sorted in non-decreasing order.

Read n on the first line of standard input, then n space-separated integers on the second line. Print the sorted squares, space-separated, to standard output.

## Examples

### Example 1

**Input**
```
5
-4 -1 0 3 10
```
**Output**
```
0 1 9 16 100
```

**Explanation:** Squaring gives 16, 1, 0, 9, 100, which sorted becomes 0, 1, 9, 16, 100.

### Example 2

**Input**
```
5
-7 -3 2 3 11
```
**Output**
```
4 9 9 49 121
```

**Explanation:** Squaring gives 49, 9, 4, 9, 121, which sorted becomes 4, 9, 9, 49, 121.
