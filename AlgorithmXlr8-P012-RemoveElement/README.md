# Remove Element

**Difficulty:** `Easy`

## Problem

Given an integer array nums and an integer val, remove all occurrences of val, keeping the remaining elements in their original relative order. Return k, the number of elements remaining after removal.

Read n and val on the first line of standard input, then n space-separated integers on the second line. Print k on the first line of output, then the k remaining elements, space-separated, on the second line.

## Examples

### Example 1

**Input**
```
4 3
3 2 2 3
```
**Output**
```
2
2 2
```

**Explanation:** Removing every 3 leaves the two 2's.

### Example 2

**Input**
```
8 2
0 1 2 2 3 0 4 2
```
**Output**
```
5
0 1 3 0 4
```

**Explanation:** Removing every 2 leaves 0, 1, 3, 0, 4 in their original order.
